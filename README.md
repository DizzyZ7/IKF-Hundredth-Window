# 🕯️ Свет в сотом окне

**У каждого своя история. Но свет один на всех.**

Интерактивный сайт новогоднего коллективного ориджинала **ИКФ**: северный городок Люсхольм, девятиэтажный дом «Альбатрос», 99 квартир и приглашение из несуществующей сотой.

**Сайт (после включения GitHub Pages):** https://dizzyz7.github.io/IKF-Hundredth-Window/

**Чат и участие:** https://t.me/chat_IKF

## Возможности

- Адаптивная зимняя страница для телефона и ПК.
- 99 интерактивных окон со сведениями о героях и ссылками на истории.
- Возможность «зажечь» окно; персональные огоньки остаются в браузере.
- Каталог историй, редактируемый через data/stories.json.
- Снегопад с учетом настройки уменьшения анимаций.
- Информация о мире, приглашение авторов, запечатанная тайна до 31 декабря.
- Без трекеров, регистрации и серверной части.

**Важно:** личные огоньки не являются общим счетчиком. Подарок и финальная разгадка отсутствуют в публичном исходном коде до даты публикации.

## Литературный канон

- Люсхольм — вымышленный североевропейский портовый город в скандинавском стиле, не Санкт-Петербург.
- Основное действие: вечер 31 декабря 2026 года; мягкая, неоднозначная мистика.
- «Альбатрос» — Маячная улица, 7; 9 этажей, 99 квартир, по 11 на этаж.
- Электричество пропадает, начинают появляться приглашения из квартиры №100.
- Первая героиня: Эйра Линдт, 28 лет, картограф, квартира №70, 7-й этаж.
- Участники не ограничены числом квартир: герои могут жить и работать в любой части Люсхольма.
- Каждый желающий пишет свою главу; редактура и публикация — у команды ИКФ.

## Как добавить историю

Откройте data/stories.json и добавьте запись (нужен корректный JSON):

~~~json
{
  "id": "author-character-slug",
  "window": 23,
  "title": "Название главы",
  "name": "Имя персонажа",
  "subtitle": "Глава 02",
  "author": "Ник автора",
  "description": "Короткая аннотация",
  "excerpt": "Небольшая цитата",
  "ficbookUrl": null
}
~~~

Поле window — номер квартиры от 1 до 99; для героев, не привязанных к дому, допускается null. После публикации заполните ficbookUrl подтвержденной ссылкой на Фикбук. Одну квартиру могут описывать несколько авторов — они будут представлены отдельными карточками в каталоге.

## Локальный запуск

Сайт не требует npm. Из корня репозитория:

~~~bash
python -m http.server 8000
~~~

Откройте http://localhost:8000/.

## GitHub Pages

Перейдите в **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**. После этого workflow в .github/workflows/pages.yml сможет публиковать сайт при каждом коммите в main. Адрес Pages указан выше.

## Обновления интерфейса

- На фасаде номера квартир идут **снизу вверх**: 1–11 на 1-м этаже, 89–99 на 9-м. Окна №67–77 находятся на 7-м этаже.
- Квартира Эйры Линдт — **№70 на 7-м этаже**, с отдельным розово-красным свечением.
- Истории доступны через поиск и фильтр по месту действия. Одна квартира может содержать несколько историй; герои города не обязаны иметь квартиру в «Альбатросе».
- На карточку окна можно поделиться прямой ссылкой вида `#window-70`.
- GitHub Pages работает через **Deploy from a branch → main / (root)**, отдельный Actions workflow не нужен.
