# Ориентиры для авторов

**Люсхольм:** вымышленный скандинавский городок на северном заливе. Порт, хвойные леса, пекарни, уютные улицы и современная инфраструктура. Не конкретная реальная страна.

**31 декабря 2026 года:** основное действие происходит вечером перед Новым годом. Мистика допускается, но остается мягкой и неоднозначной.

**«Альбатрос»:** дом на Маячной улице, 7; девять этажей, 99 квартир (11 на этаж). У дома есть соседи, гости, курьеры, прохожие; истории могут развиваться и в других районах города.

**Общая завязка:** пропадает электричество, жильцы получают приглашения из несуществующей квартиры №100.

**Участие:** один человек — одна глава, ориентир 3000–8000 знаков без жесткого лимита. Не ограничиваем число участников количеством окон. Необязательно знакомиться с Эйрой Линдт или развивать линию квартиры №99.

**Тон:** доброта, юмор, романтика, надежда, взаимопомощь, зимний уют. Печальные события возможны, но без намеренного шок-контента.

**Правила:** никаких мата, оскорблений, травли, дискриминации, плагиата, откровенного сексуального контента или чрезмерного насилия. Сюжетные пересечения с героями других участников согласовываются.

**Редактура:** проверяем хронологию и совместимость. В главе указываем настоящего автора; существенные правки обсуждаем.

**Секрет:** не публикуйте разгадку сотого окна до финала. Праздничное раскрытие запланировано на 31 декабря 2026 года.

**Связаться:** https://t.me/chat_IKF

**Канон квартиры Эйры:** №70, седьмой этаж. На фасаде дома ряды идут по убыванию этажей сверху вниз (9, 8, ... 1), а номера квартир возрастают снизу вверх (1–11 на первом этаже, 89–99 на девятом).

## Хроника и согласование общих сцен

Общие опоры мира находятся в `data/chronicle.json` → `anchors`. Не меняйте их без решения редакции.

Публикация эпизода допускается только после выхода соответствующей главы на Фикбуке и редакторской проверки. Добавьте запись в `events`:
```json
{
  "id":"unique-event-id",
  "storyId":"id-опубликованной-главы-в-stories.json",
  "title":"Название эпизода",
  "summary":"Что произошло — без спойлеров финала",
  "stage":"before",
  "status":"published",
  "sequence":10
}
```
Значения `stage`: `before`, `during`, `after`, `independent`. Порядок задается `sequence`. Отсутствующие часы не додумываем.

Персонажные связи в `data/relationships.json` → `links`:
```json
{
  "from":"character-id-a",
  "to":"character-id-b",
  "label":"Знакомые",
  "description":"Краткое согласованное описание",
  "status":"approved"
}
```
Требуется согласие обоих авторов. До согласования не добавляйте ни отношения, ни публичные эпизоды. Сцены с риском раскрыть тайну сотого окна не публикуются до финала 31 декабря.
